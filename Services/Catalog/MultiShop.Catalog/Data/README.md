# Demo ürün seçenekleri

DemoProductOptions.json mevcut 82 örnek ürünün seçenek değerlerini içerir.
Bu veriler stok veya gerçek varyant bilgisi değildir; ürün detayındaki seçim ve
sepet akışını denemek için hazırlanmıştır.

Kategorinin OptionNames alanı kullanılabilecek grupları belirler (örneğin Renk, Beden).
Ürünün Options alanı o üründe seçilebilecek değerleri tutar (örneğin S, M, L).
Bu dosyadaki değerler mevcut veritabanında yalnızca seçenekleri boş ürünlere uygulandı;
uygulama dosyayı açılışta otomatik yüklemez. Yeni ürünün değerleri admin ürün ekranından girilir.
